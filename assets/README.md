# Графика для игры (мобильная версия)

Игра ожидает следующие файлы:

- `assets/background.jpg`
- `assets/gems/gem1.png`
- `assets/gems/gem2.png`
- `assets/gems/gem3.png`
- `assets/gems/gem4.png`
- `assets/gems/gem5.png`

## Рекомендуемые размеры

### Фишки (5 штук)

- Формат: `PNG` с прозрачностью
- Размер: **128x128 px**
- Важная зона объекта: примерно 90–100 px по центру (оставить небольшой прозрачный отступ)
- Стиль: визуально одинаковый объём/контраст между всеми 5 фишками, чтобы ни одна не выглядела «сильнее»

> Технически игра масштабирует спрайт под ячейку ~35x35 px (внутри клетки 45x45),  
> поэтому 128x128 даёт хороший запас по качеству на Retina/HiDPI экранах.

### Фон

- Формат: `JPG` (или `PNG`, но в коде сейчас путь `background.jpg`)
- Базовый размер: **1080x1920 px** (портрет)
- Сюжет/узор без важных деталей по краям (фон масштабируется и может немного кропаться)
- Контраст: средний/низкий, чтобы фишки оставались хорошо читаемыми
